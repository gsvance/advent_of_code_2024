# advent\_of\_code\_2024

My solutions to Advent of Code 2024 in Python

- This was the second Advent of Code event that I ever participated in, which means I had to remember which login method I used for AoC 2023.
- For 2024, I decided to use Python instead of Rust, just to get as far as I could possibly manage. This way, the threshold for how difficult a problem would have to be to roadblock me would be higher, since Python is a more flexible and I know it a lot better.
- To get ready, I tried solving a few problems from AoC 2023 in Python as well. I also worked on a few AoC 2023 problems while waiting for the next AoC 2024 problem to be released.
